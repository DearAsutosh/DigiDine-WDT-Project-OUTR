# DigiDine 🍽️

**DigiDine** is a comprehensive **Online Food Ordering & Restaurant Management System** designed to seamlessly connect hungry customers with the best local restaurants. It provides an intuitive platform for customers to discover food and a powerful dashboard for restaurant owners to manage their business operations.

---

## 🚀 Project Overview

DigiDine bridges the gap between food lovers and restaurants by solving common challenges:
- **For Customers**: Easy access to menus, seamless ordering, and real-time tracking.
- **For Owners**: Efficient order management, menu updates, and performance tracking.

## ✨ Key Features

### 👤 For Customers
- **Restaurant Discovery**: Browse restaurants by location, cuisine, or rating.
- **Smart Search**: Real-time search for restaurants and specific food items.
- **Smart Filters**: "Veg-Only" toggle and rating-based filtering.
- **Seamless Ordering**: Easy-to-use cart system with coupon code support.
- **Real-Time Tracking**: Monitor order status from placement to delivery.
- **User Profile**: Manage delivery addresses, profile details, and order history.
- **Ratings & Reviews**: Rate orders and view feedback from other customers.

### 🏪 For Restaurant Owners
- **Order Management**: Instant notifications for new orders with Accept/Reject options.
- **Menu Control**: Add, edit, or remove menu items and manage availability.
- **Business Dashboard**: Track earnings, order history, and customer feedback.
- **Feedback System**: View and analyze customer ratings to improve service.

---

## 🛠️ Technology Stack

DigiDine is built using modern web technologies to ensure performance and reliability:
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Backend**: Node.js
- **Real-Time Communication**: Socket.io (for order updates)
- **Data Storage**: JSON-based storage / Database

## ⚙️ Installation & Setup

Follow these steps to set up DigiDine locally:

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/YourUsername/DigiDine.git
    cd DigiDine
    ```

2.  **Install Server Dependencies**
    Navigate to the server directory and install the necessary packages:
    ```bash
    cd server
    npm install
    ```

3.  **Start the Server**
    ```bash
    npm start
    ```
    *The server will typically run on port 3000 (or as configured).*

4.  **Launch the Application**
    Open `index.html` in your preferred web browser or use a live server extension to run the frontend.
